# Theater Command SDK

## Mission

The Theater Command SDK is the AI-assisted development interface for Theater Command DCS.

Its purpose is to safely coordinate development between:

- Codex
- ChatGPT
- GitHub
- DCS-SMS
- DCS Mission Editor
- DCS Runtime

---

## Responsibilities

The Theater Command SDK may:

- inspect missions
- validate missions
- inspect trigger zones
- inspect airbases
- inspect statics
- inspect templates
- analyze logs
- execute predefined development tools
- generate reports

The Theater Command SDK must never:

- modify vendor frameworks
- bypass AGENTS.md
- bypass project documentation
- execute unknown Lua code
- change campaign logic automatically

---

## Workflow

1. Read AGENTS.md
2. Read project documentation
3. Analyze repository
4. Inspect mission
5. Suggest changes
6. Wait for approval
7. Apply one change
8. Verify
9. Report

---

## Development Principle

Always prefer validation over modification.

Always inspect before changing.

Never execute destructive operations without explicit user approval.
