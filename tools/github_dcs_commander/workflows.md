# GitHub DCS Commander Workflows

## Workflow 01 — Repository Analysis

Purpose:

Safely inspect the current Theater Command repository before any implementation.

Steps:

1. Read AGENTS.md
2. Read README.md
3. Read ROADMAP.md
4. Read TASKS.md
5. Read relevant documentation
6. Identify affected subsystem
7. Report findings
8. Wait for approval

---

## Workflow 02 — Mission Inspection

Purpose:

Inspect a DCS mission without modifying it.

Steps:

1. Open mission
2. Read mission information
3. Validate naming conventions
4. Validate trigger zones
5. Validate airbases
6. Validate templates
7. Generate report

---

## Workflow 03 — Runtime Diagnostics

Purpose:

Inspect a running DCS mission.

Steps:

1. Verify DCS connection
2. Read runtime status
3. Check DCS log
4. Execute approved diagnostic script
5. Generate report

---

## Workflow 04 — Implementation

Purpose:

Safely implement one change.

Steps:

1. Analyse
2. Plan
3. Modify one file
4. Review
5. Test
6. Report
7. Wait for approval
8. Commit

---

## Workflow 05 — Release

Purpose:

Prepare a stable project state.

Steps:

1. Run diagnostics
2. Run validation
3. Verify documentation
4. Verify runtime
5. Prepare commit
6. User approval
7. Push
